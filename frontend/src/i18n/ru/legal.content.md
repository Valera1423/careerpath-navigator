# Согласие на обработку персональных данных

Я даю согласие на обработку моих персональных данных (ФИО, регион, навыки,
желаемая должность, история откликов) в соответствии со ст. 9 Федерального
закона № 152-ФЗ «О персональных данных» для целей карьерного сопровождения.

Согласие может быть отозвано в любой момент:
- через настройки профиля (кнопка «Удалить профиль»);
- письмом на адрес privacy@careerpath.example.

# Политика конфиденциальности (краткая версия)

1. Мы храним минимум: ФИО (опционально), регион, навыки, желаемую должность.
2. Для Employer API передаются только анонимизированные данные — без ФИО,
   email, точного ID. Передача возможна только при включённом opt-in.
3. Мы не передаём данные третьим лицам без вашего согласия.
4. Удаление профиля удаляет все связанные записи в течение 30 дней.
